# Поиск по нефтегазовой документации — RAG и MCP

## Задача

Находить релевантные фрагменты документов и предоставлять поиск пользователю бота либо клиенту с поддержкой MCP.

## Моя роль

Разработка прототипов поиска и подключения к базе документов.

## Результат

Подготовлены два связанных по задаче компонента: MCP-сервер с инструментом поиска через embeddings и Qdrant и n8n-сценарий RAG-бота для работы с документами. Они представлены в одном кейсе как два способа доступа к документальному поиску; единая промышленная поставка не заявляется.

## Статус

Прототипы. Качество ответов требует оценки на размеченной выборке; наличие поиска само по себе не гарантирует достоверность ответа модели.

## Технологии

Python, FastMCP, Qdrant, embeddings, n8n, Telegram, LLM.

## Возможности и использование

MCP-компонент предоставляет инструмент поиска по документам для клиента, поддерживающего этот протокол. RAG-компонент реализует отдельный сценарий работы пользователя с документами через бота.

## Архитектура и технические решения

В MCP-сервере запрос преобразуется в векторное представление и используется для поиска в Qdrant. Во втором компоненте workflow n8n связывает обработку документов, индексирование, поиск и формирование ответа через LLM и интерфейс Telegram.

Компоненты объединены в портфолио общей задачей документального поиска. Их наличие не означает, что они развёрнуты как одна система. Качество поиска и ответов требует отдельной оценки на эталонной выборке.
