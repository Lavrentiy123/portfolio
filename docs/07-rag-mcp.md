# Поиск по нефтегазовой документации — RAG и MCP

## Задача

Находить релевантные фрагменты документов и предоставлять поиск пользователю бота либо клиенту с поддержкой MCP.

## Моя роль

Разработка прототипа RAG-сценария на n8n и работа с подключением документального поиска через MCP. Эти работы не представлены как единая промышленная система.

## Результат

Подготовлен n8n-сценарий работы с документами через бота: обработка, индексирование, поиск и формирование ответа с помощью LLM. В отдельной работе настроено использование документального поиска через MCP-клиент.

## Статус

Прототипы. Качество ответов требует оценки на размеченной выборке; наличие поиска само по себе не гарантирует достоверность ответа модели.

## Технологии

n8n, Telegram, LLM API, RAG, embeddings, MCP.

## Возможности и использование

RAG-сценарий помогает искать сведения в документах через бота. Подключение поиска через MCP позволяет обращаться к документальной базе из клиента с поддержкой протокола. Это два отдельных способа работы с документами.

## Архитектура и технические решения

Workflow n8n связывает обработку документов, индексирование, поиск и формирование ответа через LLM и интерфейс Telegram. В отдельной работе документальный поиск подключается как MCP-инструмент. Собственная разработка всей подключаемой поисковой системы не заявляется. Качество ответов требует оценки на проверочной выборке.
