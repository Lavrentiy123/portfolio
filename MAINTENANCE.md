# Обновление портфолио

В README находятся десять проектов одним списком: описание, личная роль, результат и ссылка на подробную документацию. В `docs/` хранится описание исходного продукта: задача, возможности, архитектура, технологии, вклад и стадия.

Для корпоративных проектов публикуются только описания. Код, даже после удаления данных и реквизитов, не добавляется без отдельно подтверждённого права на публикацию. Резюме коллеги, переписки и материалы заказчиков в портфолио не загружаются.

Для открытых учебных и хакатонных разработок сохраняются ссылки на исходные репозитории. Не нужно переносить код в портфолио после каждого изменения. Обновляйте описание при изменении роли, возможностей, стадии или подтверждённого результата.

Целевые показатели, демонстрационные расчёты и измеренные результаты эксплуатации обозначаются отдельно. Не добавляйте эффекты без подтверждения и не выдавайте прототип за внедрение.
