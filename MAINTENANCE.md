# Как обновлять портфолио

В README находятся десять проектов одним последовательным списком. Код продуктов хранится в исходных репозиториях: его не требуется копировать в портфолио после каждой доработки.

Обновляйте карточку, когда меняются роль, результат, стадия или ссылка на демонстрацию. Для промежуточной правки кода переписывать описание проекта не нужно.

Указывайте измеримый эффект только вместе с подтверждением: на какой выборке, в какой версии и каким способом он получен. Целевые показатели, демонстрационные расчёты и результаты эксплуатации описывайте отдельно.

Для новой публичной демонстрации добавьте прямую ссылку и проверьте её без входа в аккаунт. Локальный скрипт называйте локальным примером; файл HTML на GitHub — файлом для скачивания, пока он не размещён как сайт.

Корпоративные данные, внутренние документы, реквизиты подключений и закрытый код не переносите в публичное портфолио. Добавление ссылки на закрытый репозиторий не делает его общедоступным.
